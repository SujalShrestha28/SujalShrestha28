## 🚀 Featured Projects

### 🏥 Online Medical Laboratory Management System

A full-stack, role-based web platform that connects patients with medical labs — built entirely from scratch as a BCA project.

**What it does:**
- 🔍 **Patients** can discover nearby labs, book tests, pay online, track appointment status, and download reports
- 🧪 **Lab Staff** can manage tests, handle appointments, verify payments, and upload result files
- 🛡️ **Admin** can verify lab registrations and manage platform data

**Some interesting technical bits:**
- Haversine formula implemented in `HaversineUtil` to compute real distances between patient and lab coordinates for nearest-lab discovery
- Leaflet + OpenStreetMap for interactive map location picking during lab registration
- BCrypt password hashing for secure auth
- Role-based session authorization across all panels
- DB-level triggers for appointment slot conflict prevention and data integrity

### 🎬 YoutubeTools

A lightweight Spring Boot web app that gives you SEO tags, thumbnail extraction, and full video details for any YouTube video — all in one place.

**What it does:**
- 🏷️ **SEO Tag Generator** — enter a video title, instantly get tags from similar top-ranking videos plus related ones for broader coverage, with a one-click copy button
- 🖼️ **Thumbnail Extractor** — paste any YouTube URL or video ID to preview and download the highest quality thumbnail
- 📋 **Video Data Retriever** — fetches full metadata: title, channel, publish date, description, and all tags in a clean dark/light mode UI
